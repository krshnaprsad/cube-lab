Cube Lab

Match a look, paint with a palette, blend LUTs, fix broken ones. One .cube file for Premiere Pro and DaVinci Resolve

v1.2.3

Pick a still with the look you want. Cube Lab builds a LUT that moves your frame toward it.

Strength is how far toward the reference you go. Brightness matches the light and dark balance. Colour matches the tint and richness.

Pick colours, and Cube Lab builds a LUT that paints your footage with them. Start from a Gradient Lab gradient, a palette from your own frame, or your own colours.

How it paints

Gradient map swaps each brightness for a colour from your gradient, so shadows get the first colour and highlights the last. Colour wash keeps your picture's own light and dark and only takes the tint from the gradient. Strength is how far toward the colours you go.

Stack LUTs in order and set how strong each one is. They get baked into one new file.

    Add two or more LUTs. They run top to bottom, so put a log or colour fix first and the creative look after it.

    Open any .cube file. Cube Lab checks it and can save a repaired copy.

      How to use it in your editor

      Premiere Pro. Select the clip, open Lumetri Color, go to Creative, open the Look menu, choose Browse and pick your .cube file. The Intensity slider there works on top of the Strength you set here.

      DaVinci Resolve. Saving the file is not enough. You have to copy it INTO Resolve's LUT folder. Open Project Settings, then Color Management, then Lookup Tables, and click Open LUT Folder. Paste the .cube file into the folder that opens. (Or on the Color page, right-click in the LUTs panel and choose Reveal in File Explorer, then paste it there.) Back in Resolve, right-click the LUTs panel and choose Refresh, or restart Resolve. Then find it in the LUTs panel, or right-click a node and pick it under 3D LUT.

      Both apps read the same file. Nothing here installs into an app for you, a web page is not allowed to write into your program folders.

      Why I built this

      The idea for Cube Lab came from my friend Rishi. He suggested that building something like this would be good, and I made Cube Lab from his suggestion.

      I watch a lot of reels, and every creator does something I want to try in my own way. One day I wanted my video in the colour theme of Blade Runner. The LUT for a look like that is hard to find. It is usually paid, and matching it by hand in DaVinci Resolve or Premiere Pro takes forever.

      Then I learned that a LUT can be built from images, so I built it and put it on GitHub. Now I take a screenshot of the film whose look I want, add a frame from my own work, and Cube Lab matches the colour. I download the .cube file and use it in any project.

      It is free, and I will keep adding to it.
